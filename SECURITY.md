# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within AudioWaveLib, please send an email to Sebastien Rousseau via [security@sebastienrousseau.com](mailto:security@sebastienrousseau.com).

Please provide:
- A description of the vulnerability and its potential impact.
- Steps or code to reproduce the issue.
- Details of the affected environment (OS, Swift version, target platform).

All security vulnerabilities will be promptly addressed.
